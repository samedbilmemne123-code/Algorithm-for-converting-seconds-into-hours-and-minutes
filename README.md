# Seconds to Hours and Minutes Converter

A simple C program that converts a given time in seconds into hours, minutes, and remaining seconds.

## 🚀 Features
- Takes total seconds as user input
- Calculates equivalent hours, minutes, and seconds
- Lightweight and beginner-friendly C implementation

## 🛠️ How to Run
1. Open terminal or command prompt
2. Compile the `main.c` file using a C compiler (e.g., GCC):
   ```bash
   gcc main.c -o main
